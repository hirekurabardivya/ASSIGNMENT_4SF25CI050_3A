File Handling:

• open() –  It helps to open a file.
• read() – It helps to reads file contents.
• write() – It helps to writes content present in the perticular file.
• readlines() – It reads lines present in the file.
• split() – It helps to separates words.
• len() – It counts elements present in the file.
• replace() – Replaces text present in the file.
• with open() – Handles files safely.

Numpy:

• np.array() – It helps to creates an array.
• np.random.randint() – Generates random integers given in the range.
• arr[:, 2] – Helps to access the columns.
• np.diag_indices() – Selects diagonal elements.
• np.concatenate() – It helps to combines arrays.
• reshape() – Changes array dimensions.
• np.sort() – Sorts array elements.

Pandas:

• pd.DataFrame() – It helps creates a DataFrame.
• df.loc[] – Selects rows and columns using labels.
• df.drop() – Removes rows or columns.
• df.fillna() – It is used to handle the missing value in the DataSet.
• df.isnull() – Checks missing values.
• df.groupby() – Groups data.
• pd.merge() – Combines DataFrames.
• apply() – Applies a function.
• lambda – Creates a small anonymous function.
